## 代码改动（已实现）

- **新增 `internal/cli/help.go`**：`helpText` 常量（分六组：基本 / 前置与能力 / 行为控制 / 调试与资源 / 输出与日志 / 帮助）+ 退出码表 + 5 条示例 + 文档指引；`helpRequested()` 独立扫描 `-h` / `-help` / `--help`（不依赖 flag 内建的 ErrHelp，以便区分"想看帮助"与"参数写错"）；`printHelp(w)` 首行带版本。
- **`internal/cli/cli.go`**：在 `Run` **最前面**（早于 `taskID()`、结果对象、日志文件的创建）拦截：
  - `len(args) == 0` → `printHelp(stderr)` + 退出 **2**，**不产出结果 JSON、不建日志**
  - `helpRequested(args)` → `printHelp(stdout)` + 退出 **0**
  - 自定义 `fs.Usage` 为**一行摘要 + 指向 `--help`**（未知参数时不刷整屏帮助）
  - `flag.ErrHelp` 分支改为 `printHelp(stdout)` + 0
- **`internal/cli/cli_test.go`**：新增 3 个用例 —— `TestHelpGoesToStdoutWithZeroExit`（4 种写法的 help 均走 stdout、退出 0、stderr 为空）、`TestNoArgumentsPrintsUsageWithoutArtifacts`（退出 2 + 用法在 stderr + **工作目录零产物**）、`TestUnknownFlagPointsToHelp`（提示参数名 + 指向 --help）。
