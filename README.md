# AutoTrigger 自动安装工具

Windows 离线自动安装/触发工具，可处理文件或文件夹，尝试静默安装与安装向导自动操作，并记录执行日志和结果。提供图形界面和命令行。

项目源码在 `src/`，本地运行与测试目录为 `dist/`，文档在 `docs/`。构建后运行 `dist/AutoTrigger.exe`；交付包中程序直接位于包根目录。

## 简单使用

1. 双击 `AutoTrigger.exe`，建议以管理员身份运行。
2. 点击 **检查环境**。完整交付包中的 7-Zip 和 OCR 离线包会按需部署、检测，不联网下载；缺失时根据提示补齐。
3. 点击 **新建任务**，选择安装包或文件夹，然后运行。
4. 在任务列表打开 **任务详情**，查看进度、执行日志和结果 JSON；可停止任务或重新安装。

管理员确认（UAC）需要核对来源后手动批准，工具不会自动绕过。任务结束不一定代表安装成功，请以任务详情为准；安装完成也不保证软件已激活或可正常使用。

## 数据与模板

在 **设置 → 基础设置** 指定统一数据目录，默认 EXE 同级：

- `logs`：执行日志。
- `results`：结果文件。
- `templates`：模板与捕获图片。
- `third_parties`：7-Zip、OCR 离线包和部署文件。
- `config`：配置、任务历史和界面偏好。

修改目录并保存时可选择复制迁移；原数据保留，目标已有数据不覆盖。EXE 同级的 `config/data-location.json` 记录目录位置。旧 `third_party` 等目录可在首次提示中复制迁移。

在 **模板管理** 新建模板、捕获图片并标记动作，勾选后供后续任务匹配。右上角支持批量 ZIP 导入、导出；导入后需自行勾选启用。

## 命令行

在程序所在目录执行（本地项目为 dist）：

```powershell
.\AutoTrigger.exe --check-prereq --json
.\AutoTrigger.exe --input "D:\安装包\setup.exe" --output "D:\结果\result.json"
.\AutoTrigger.exe --help
```

只检测、不部署依赖时加 `--no-deploy-deps`。缺少离线包时不会自动下载；OCR 暂不可用时可使用 `--no-ocr`。更多参数见 `--help`，配置字段说明在设置的高级配置中查看。

<details>
<summary>受控测试机：调整 UAC 通知（可选，日常电脑不推荐）</summary>

关闭通知会降低安全防护，请仅在有管理权限的受控测试机使用：
1. 在开始菜单搜索“更改用户账户控制设置”，记下当前滑块位置。
2. 选择“从不通知”，点击确定并批准权限请求；按系统提示重启。
3. 测试完成后恢复原位置。此设置不保证所有安装器都能无人值守，也不代替管理员权限。

工具不会替用户关闭 UAC，日常电脑优先保持默认设置并以管理员身份运行可信程序。
</details>

支持目标为 Windows 7 SP1 x64 及以上；Win7 实机兼容尚未完整验收。Windows 内置 OCR 当前未实现，锁屏或 UAC 安全桌面不能保证自动操作。
