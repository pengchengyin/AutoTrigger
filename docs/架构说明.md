# 架构与扩展

`cmd/autotrigger` 唯一装配 Windows 实现或非 Windows stub。`internal/cli` 处理参数、配置、日志与结果生命周期，`internal/core` 仅通过 `internal/core/ports` 调用进程、GUI、文件关联、压缩、挂载、证据源和锁。Core、verify、activity 不导入 platform。

| 包 | 职责 |
|---|---|
| core/detect | 文件头优先类型识别 |
| core/layout | 入口排序、作者提示、介质分类、强制排除 |
| core | 逐文件基线、多轮尝试、批量、递归、超时和 journal 回调 |
| verify | 平台证据 diff、S/A/B/N 仲裁、置信度和稳定性等待 |
| activity | CPU/I/O/进程树/GUI/快照变化重置启动与静默计时 |
| platform/windows | Win32/UIA/COM/GDI、Job Object、注册表、事件日志、关联与 ISO |
| platform/windows/winver | 版本、DPI 动态 API 和 AVX CPU/OS 能力 |
| platform/stub | 非 Windows 明确 unsupported，保持跨平台编译 |
| gui | 语义白/黑名单、三级降级、动作上限、截图去重与 dump |
| ocr | 进程复用、超时、重启、原生 score、环回 TCP/HTTP 和 TSV |
| archive | 外部 7-Zip、结构化 -slt 列表、路径与体积校验 |
| resources / config | 内嵌规则、增量覆盖、深合并、校验和 digest |
| output / pkg/schema | 单 JSON、原子替换、journal 与对外固定模型 |

## Win7 差异

构建锁 Go 1.20.x、amd64、CGO=0。使用系统 DLL LazyProc，DPI 新 API 不存在时回退系统 DPI；截图按版本选择 PrintWindow 标志。CPU AVX 检查 CPUID、OSXSAVE 与 XGETBV，不将虚拟机暴露 CPU 特性误当作 OS 支持。Win7 不原生支持嵌套 Job Object，无法绑定时明确报错而不允许样本脱离监管。

UIA 和截图有独立辅助进程，1.5 秒超时终止，避免跨进程 COM 或 PrintWindow 阻塞。控件坐标统一为物理屏幕像素，截图原点是窗口矩形左上角，点击不重复缩放；点击前检查窗口归属、边界与前台焦点。命名互斥量绑定当前 OS 线程，释放锁也在该线程，避免 Go 协程迁移导致 ReleaseMutex 失败。

## 平台扩展

增加平台实现时替换 ports：ProcessRunner、FileOpener、InstallerTrigger、EvidenceSource、GUIAutomator、DiskMounter、Lock、PrereqManager。证据源将 Linux 包数据库/macOS receipts 归一化为平台独立基线；分级与仲裁仍在 verify。扩展需要相应的平台默认监控目录与命令资源。Linux Wayland 和 macOS 辅助功能权限必须明确能力限制。

## 实现取舍

串行执行维持文件级证据归因。前置安装包优先但不结束主包。Readme/autorun 只提升已存在文件的优先级，不执行其声明字符串中的任意 shell 命令。文件扫描有预算，截断后停用减少实体反证据。成功参数尝试会覆盖之前失败参数的 N1，但历史 attempt 仍保留；同一证据 ID 只计一次，反复退出 0 不会累积成两条 A 证据。

发布限制见验收状态：缺乏真实模板、Win7 环境与部分安装器材料时，不把 mock、合成图或开发交付当作完整验收。
