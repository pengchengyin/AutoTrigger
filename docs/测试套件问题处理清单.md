# 测试套件问题处理清单

核对日期：2026-10-14。来源：AutoTrigger-TestSuite 的 `reports/issues/ISSUE-01` 至 `ISSUE-36`、历史复测报告及当前源码。此文档是源码处理记录，不是新一轮安装成功率报告。

## 判断口径

- **本轮修复**：已有代码变更、回归测试和独立提交；仍需同样本实机复测。
- **部分处理**：只解决明确的子问题，不关闭整个 issue。
- **已有修复**：当前源码已有对应修复，不重复改写；历史复测不等同于当前二进制验证。
- **不改契约/样本**：现象符合 PRD 或样本不完整，不通过放宽判定制造成功。
- **待处理**：确有风险，但当前证据或实现不足以安全闭环。

## 本轮验证

使用 Windows Go 1.20.x，在 `src` 下执行：

```text
go test ./...
go vet ./...
go build -o ../dist/AutoTrigger.exe ./cmd/autotrigger
go run ./tools/pe-check ../dist/AutoTrigger.exe
```

全量测试、静态检查和构建通过；新增回归覆盖权限错误、UIPI 传播、无活动最终状态、重启码、无窗口联网提示、异常采样间隔、关联宿主、A3 目录证据、候选耗尽、说明文件和解压错误。相关业务场景主要使用可控测试接口，不替代安装器实测。
