当前主机实测于 2026-09-30，内核 10.0.26200，PowerShell 5.1；系统 WMI 自报 Windows 10 Home China。这里只记当前主机通过，不归入干净 Win10 VM 或 Win7 通过。成功脚本、GUI、ZIP 与输入失败四份结果经过 Ajv 2020-12 校验，summary 互斥桶之和与 results 长度一致。

第三方 Paddle/Rapid 压缩包已下载，实际字节数与官方发行长度一致，并用 7-Zip t 完整校验通过。没有安装第三方软件到系统，测试引擎只解压到工作目录。原有 verify-ocr.ps1 修复了 Rapid 命令行双横线参数及可变集合初始化两处实测问题。

构建环境提示：本机 `D:\Go\src` 下存在 3358 个 `*.old.go` 副本（覆盖 536 个目录，疑为安天安全软件的文档备份所致），Go 会将其视为包的一部分而使 `go build` 直接失败（`found packages X and X_test` / `import cycle not allowed`）。清理原目录后即可正常构建；本文列出的编译与实测结果来自"另建干净 GOROOT（junction 复用 bin/pkg + 只复制不含干扰的 src）"的旁路构建，源码与产物一致。

## 正式发布卡点

补充真实母版和截图来源，运行 template-gen --release 与模板源图自检。提供干净 Win7/Win10 VM，复测真实 Inno、NSIS、MSI、InstallShield、OCR、自绘 UI 和两类 ISO；并在 **Win7 SP1 x64 与 125%/150% DPI** 下复测图形界面的控件布局与文件/文件夹对话框（A33 ⑩）。完成 EDR 与完整离线包部署验收后，才能将交付 manifest 的 release_ready 标为 true。
