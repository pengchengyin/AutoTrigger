# 历史测试效果摘要

本篇汇总工具在真实安装器与相关专项场景上的测试效果，数据来自对原始结果 JSON 的只读核对，未在本仓库复制日志与样本，也未重新执行其中的安装器。样本与完整报告的发布入口为 [AutoTrigger-TestSuite](https://github.com/pengchengyin/AutoTrigger-TestSuite)。

## 1. 版本与环境

| 项目 | 说明 |
|---|---|
| 日期 | 2026-10-11 至 2026-10-12 |
| 工具 / Schema / 资源版本 | 0.1.0 / 2.8 / 0.1.0 |

| 测试方法 | 真实安装器按类别分组执行；另有压缩包整组长任务与专项验证 |

工具版本号 0.1.0 不代表所有记录来自同一二进制。这里的历史统计也不是 `v0.1.0-preview.20261014.2` 的完整安装复测结果。

## 2. 真实安装器输出

仅统计 01–05 组的 22 个已提权真实安装器；每组 results 数量与 summary.total 一致，这里只计算 final_status=install_completed 的记录占比。

| 类别 | 安装完成输出 | 部分完成输出 | 总样本 | 安装完成输出占比 |
|---|---|---|---|---|
| Inno Setup | 4 | 1 | 5 | 80.0% |
| NSIS | 5 | 0 | 5 | 100.0% |
| MSI | 5 | 1 | 6 | 83.3% |
| WiX Burn | 2 | 1 | 3 | 66.7% |
| 其他厂商安装器 | 2 | 1 | 3 | 66.7% |
| 合计 | 18 | 4 | 22 | 81.8% |

**81.8% 是这 22 个已提权真实安装器的工具输出比例，不是所有样本、所有软件或最新版的成功概率，也不是软件业务功能的独立验收比例。** 未验证、部分完成、已安装、已触发及跳过均未计入分子；没有为了提高比例而排除缺文件样本。

关键限制：

- Notepad3、VC_redist、VeraCrypt 和 MobaXterm 的 final_status 均为 install_partial。
- MSI 汇总段曾将 MobaXterm 写成“失败”，但逐项表与 03-group.json 为 install_partial。这里以结构化 JSON 为准；样本缺少外部 .dat 文件仍是该项的重要限制。
- ShareX 和 TeraCopy 虽输出 install_completed，但记录存在安装后应用窗口拖至超时的情况。因此不能将这 18 个结果宣传为“全部自然结束、全程无等待问题”。
- 第 06 组压缩包曾整组崩溃，JSON 的 total=0、finished_at 无值，不并入 22 个安装器分母，也不能将 0 条记录当作零失败。应单独披露稳定性问题。
- 另有单包复跑“8/8 正常结束”的记录，这是进程稳定性指标，不是 8 个包均安装成功。

## 3. 稳定性与专项验证

修复效果按 7 个检查项汇总为 **5 项完全通过、2 项部分通过/部分验证**；表头虽列 8 行，但“合法样本误杀”和“真黑名单负向对照”在结论中合并为一项。不把这个比例当作安装成功率，也不据此宣称全部问题已修复。

| 检查项 | 验证证据 | 结论及限制 |
|---|---|---|
| 回调耗尽崩溃 | GRP06.json 保存 1621 条结果，38 分 12 秒左右，finished_at 有值，error=null，truncated=false | 整组不再因原回调耗尽问题崩溃；长耗时与 GUI 收敛问题仍需优化。 |
| 合法样本误杀与负向对照 | 原误杀样本进入执行；含 11 个陷阱的 A25-01 未出现 VIOLATION 哨兵 | 判通过；INNO-06 单次任务中断，不能宣称该样本完成安装。 |
| 回滚反证据保留 | A29-07 输出 install_partial，evidence_conflicts 保留 6 条 N6 | 判通过，未继续把该回滚样本输出为安装完成。 |
| 截断快照判定（A29） | A29-01 为 install_unverified；A29-08 为 failed | 判通过，退出码等独立证据仍保留。 |
| 证据路径诊断 | S2/N5/N6 的 source/detail 提供实际路径及数量 | 判通过；A3 路径说明仍有不足。 |
| 活动感知与判定（A30） | A30-03 为 killed_on_timeout；A30-05/09 仍为 install_partial | 部分通过，A30-05/09 的背景活动证据及状态口径需继续核对。 |
| VC_redist 升级判定 | 未出现 N4，也未跨架构牵连 | 部分验证；主要是已装状态下的无操作运行，未复现旧 x64 被替换的真实升级场景。 |

压缩包的 1621 条结果分类为：安装完成 4、未验证 2、部分完成 8、已触发 7、失败 1、跳过 1599，其余状态为 0。分类合计 1621，与 results 数量及 summary.total 一致。该数量包含解压展开子项，不是 1621 个软件；绝大多数是跳过项，不能用来声称“大规模安装全部成功”。

## 4. 复测建议

建议通过测试套件在专用虚拟机或可恢复快照中复测，记录工具 EXE SHA-256、系统、管理员权限、DPI、OCR 与模板配置。分开报告真实安装器、合成故障样本、压缩包和文档触发；原本预期失败或跳过的合成样本应按预期一致性评估，不套用安装完成率。完整复测后才更新最新版效果数据。
