# Win10 样本测试问题修复记录

依据用户提供的 2026-10-10 报告、问题清单与逐样本 CSV。报告是测试证据，预期行为仍以 PRD 为准。报告列出的虚拟机原始 `at-run`、安装器与哨兵未随这三份文件提供；本机回归不等于原 Win10 虚拟机样本全部复测通过。

| 编号 | 处理与验证 |
|---|---|
| D01 | 单文件输入、快捷方式目标及执行前统一检查强制禁执行规则；7 个报告中的危险名称均验证没有启动、没有 attempt。帮助文档规则仅用于包入口筛选。 |
| D02 | MSI 中英文“安装成功或错误状态”按数值解析，成功码沿用 0/3010/1641；1602/1603/1620 及无效状态不再产生 B1。 |
| D03 | 普通目录逐文件批处理，不套用包收敛及阶段入口限制；压缩包/映像或有明确 P0 说明/autorun 线索的目录保留包策略。三独立样本及明确包目录回归通过。 |
| D04 | 文档宿主首个活动后不再用纯 CPU/I/O 或全局目录变化重置空闲计时，仍响应 GUI/进程树变化；I/O 排除 OtherTransferCount；心跳显示实际监控 PID 并说明活动不等于成功。被动宿主持续 CPU/I/O 回归通过，原 WordPad 待 VM 复测。 |
| D05 | 文档宿主仅判触发/失败/超时，不生成安装证据或置信度；超时后的 A/B 弱证据不再升级为安装成功，S 级仍按 PRD 保留。文档有落盘仍不判安装回归通过。 |
| D06 | 保存运行期新增卸载项/目录及稳定期快照，复检最终仍存在；消失产生 N4/N6，并判部分完成，不被退出码 0 覆盖。截断快照不用于目录消失反证据；瞬态落盘回滚回归通过。 |
| D07 | N 级与任意 S/A/B 正证据同现均记录冲突；跨尝试失败不被后续弱证据/超时洗掉，只有后续自然成功且有 S 级成果可解除历史失败。无副作用的 N+B、N+A、N+S 回归通过。 |
| D08 | 原目标不存在时，按 MS-SHLLINK 的 RelativePath 与快捷方式所在目录恢复搬迁后的目标；不使用进程工作目录，参数仍由 COM 获取。Unicode 相对目标、真实 COM 加载、截断文件回归通过。 |
